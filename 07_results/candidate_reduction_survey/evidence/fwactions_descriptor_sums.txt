#   DEFAULT_SG_PAGE_SIZE (descriptor_list.hpp:42) forced for config buffers (config_buffer.cpp:300-311,
#   FORCE_DEFAULT_PAGE_SIZE); no "Desc page size ... not optimal" warning was logged, so the page was not enlarged.
#   descs x 512 is an upper bound: each CCW DMA transfer ends with a partial page and one NOP-padding descriptor is
#   added per config buffer (config_buffer.cpp:132-156). HEF ground truth = sum of write_data_ccw_ptr.size (hef_proto_bytes.txt).
# Context time = last - first action timestamp in the context, clock_cycle_MHz = 200 (from the JSON).
# Inter-context / DDR actions in the JSON carry no byte counts (only channel/stream indices), so edge bytes come from the HEF.

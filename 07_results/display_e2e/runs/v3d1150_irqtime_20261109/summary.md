# 표시 통합 e2e — 미계수 인터럽트 처리 시간, 현재 바이너리(dc447c5)로 다시 잼 (2026-11-09)

[`v3d1150_irqtime_20261016`](../v3d1150_irqtime_20261016/summary.md)의 재측정입니다. 이 커널은 `IRQ_TIME_ACCOUNTING`이 꺼져 있어, CPU가 유휴일 때 처리된 hardirq·softirq 시간이 프로세스 CPU 계수에서 빠집니다. 헤드라인 회차를 현재 바이너리로 다시 쟀으므로([`v3d1150_quiet_perfgov_20261109`](../v3d1150_quiet_perfgov_20261109/summary.md)), 그 보정 값도 같은 코드에서 다시 쟀습니다. 결정: 표 23 재측정과 함께 IRQ 보정 회차도 다시 잰다 (사용자 결정, 2026-11-09).

**결론부터 적습니다.**
- 미계수 몫은 이전 회차와 같습니다: 기준 0.213, 제안(표시 on, 최대속도) 0.319 ms/f입니다(이전 0.211, 0.328).
- 헤드라인에 더하면 2.460 + 0.213 = 2.673 → 1.844 + 0.319 = 2.163 ms/f, 감소율 **−19.1%**입니다(이전 −11%).
- 소스 30 fps 표시는 1.989 + 0.394 = 2.383 ms/f, 기준 대비 −10.8%입니다(이전 −5%).

## 3. 결론

**1. 미계수 몫은 코드 변경과 무관합니다.** 네 설정 모두 이전 회차와 0.01 ms/f 안에서 같습니다. 인터럽트 수는 설정에 따라 정해지고(표시 on에서 늘어남), 응용 코드의 CPU 절감과는 관계가 없습니다.

**2. 보정해도 결론의 방향은 그대로이고, 폭은 이전보다 큽니다.** 제안 경로가 늘리는 미계수 몫(+0.106)이 헤드라인 감소폭(0.616)보다 훨씬 작아, 보정 뒤에도 −19%가 남습니다.

## 4. 주의·남은 일

- 기준 경로 3회 중 1회가 0.282로 높습니다(나머지 0.211·0.213). 중앙값을 씁니다.
- 실행 직전 Hailo는 64.4~71.7 °C, SoC는 68.6~74.1 °C였습니다(표시 벤치의 냉각 규칙: 75 °C 초과 시에만 냉각. 이전 회차 56.6~71.6 °C).
- 헤드라인(5회)과 미계수 몫(3회)은 같은 세션의 다른 실행이라, 더한 값은 중앙값끼리의 합입니다(이전 회차와 같은 방식).
- 논문 반영은 사용자 확인 대상입니다.

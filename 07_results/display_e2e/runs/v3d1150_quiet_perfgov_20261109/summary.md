# 표시 통합 e2e — 논문 헤드라인 회차를 현재 바이너리(dc447c5)로 다시 잼 (2026-11-09)

논문 헤드라인(표 23, "파이프라인 호스트 CPU 2.444 → 2.044 ms/프레임, −16%")은 [`v3d1150_quiet_perfgov_20261016`](../v3d1150_quiet_perfgov_20261016/summary.md)(Q, 코드 `2f2d3d0`)의 값입니다. 그 뒤 `c97c274`(2026-11-06)가 GPU 후처리 경로의 응용 CPU를 줄였으므로, 같은 벤치·설정·집계로 현재 바이너리에서 다시 쟀습니다. 결정: 표 23을 현재 바이너리로 재측정한다 (사용자 결정, 2026-11-09).

**결론부터 적습니다.**
- 기준 경로(호스트 후처리, 표시 없음)는 2.444 → **2.460 ms/f**로 그대로입니다.
- 제안 경로(GPU 후처리, 표시 on, 최대 속도)는 2.044 → **1.844 ms/f**입니다. 감소율은 −16.4%에서 **−25.0%**로 커졌습니다. 같은 회차 짝 5개도 모두 −23.5~−25.4%입니다.
- 줄어든 몫은 거의 응용 CPU입니다(1.356 → 1.189). 컴포지터(0.378 → 0.367)와 커널 스레드(0.316 → 0.289)는 거의 같습니다.

## 3. 결론

**1. 헤드라인은 −16%에서 −25%로 바뀝니다.** 기준 경로가 같고(2.444 → 2.460, 범위 겹침), 제안 경로만 0.20 ms/f 줄었습니다. 줄어든 몫의 대부분(0.167)이 응용 CPU이고, 이는 `c97c274`의 두 변경(HailoRT 사전 매핑 크기 맞춤, 후처리 명령 버퍼 사전 기록)과 맞습니다([`cpu_trim`](../../../technique_ablation/runs/cpu_trim/summary.md)).

**2. Q보다 흔들림이 작습니다.** 같은 회차 짝의 폭이 −14~−24%(Q)에서 −23.5~−25.4%로 좁아졌습니다. Q의 기준 경로 범위(2.422–2.678)에 있던 튀는 실행이 이번에는 없었습니다.

**3. 미계수 인터럽트를 더한 값은 [`v3d1150_irqtime_20261109`](../v3d1150_irqtime_20261109/summary.md)에 있습니다.**

## 4. 주의·남은 일

- 1회 세션입니다. Q처럼 앞 회차(ondemand)와 짝을 짓지 않았습니다. 거버너가 다른 회차의 CPU는 비교하지 않습니다.
- 표시 벤치의 냉각 규칙은 칩이 75 °C를 넘을 때만 65 °C로 식히는 것이라, 실행 직전 Hailo가 63.4~70.2 °C였습니다(SoC 67.0~71.4 °C). Q도 같은 규칙으로 55.3~70.3 °C였습니다. HailoRT 경고는 0이었습니다.
- 배치 2 계열 운용점의 값입니다. 확정 구성(O2, 배치 1)의 응용 CPU는 [`technique_ablation/runs/rerun_dc447c5`](../../../technique_ablation/runs/rerun_dc447c5/summary.md)에 있습니다.
- 논문 반영은 사용자 확인 대상입니다.

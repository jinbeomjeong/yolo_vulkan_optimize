# 회차 o2_display_40min — 확정 구성(O2) + 표시 on 40분 연속 운용

후속 4번(사용자 승인 2026-11-06)의 회차입니다. 상위 [`thermal_soak`](../../summary.md)(2026-10-11)은 표시 off에서 b2s4·b8s16만 40분 돌렸고, 재지 않은 것에 표시 on을 적었습니다. 논문 §7.4 (1)도 "최소 지연 운용점(배치 1은 처리량이 NPU 클럭을 따르므로 버림률이 늘 수 있다)의 연속 운용은 검증하지 않았다"고 적었습니다. 그 빈칸을 확정 구성(O2)에 표시까지 켠 채로 채웠습니다.

**결론부터 적습니다.** 40분 동안 아무것도 변하지 않았습니다.
- Hailo 칩은 88.6 °C에서 평형을 이뤘고, 클럭 강등이 시작되는 약 104 °C(상위 회차)에 닿지 않았습니다. HailoRT 경고는 0건입니다.
- 5분 구간 8개의 처리량은 24.28~24.32 FPS, 입력 버림은 18.85~18.98%입니다.
- 도착 기준 지연 중앙값은 53.21~53.30 ms, 도착 → 화면 중앙값은 71.15~71.20 ms로, 짧은 측정과 같습니다.

## 3. 결론

**1. 확정 구성은 냉각 장치 없이 40분을 그대로 버팁니다.**
- 배치 1의 NPU 부하(장치 주기 41 ms 중 처리)는 b2s4·b8s16보다 가벼워, 칩이 88.6 °C에서 평형을 이룹니다. 상위 회차에서 클럭 강등이 시작된 약 104 °C(orange zone)에 15 °C쯤 못 미칩니다.
- 논문 §7.4 (1)이 걱정한 "배치 1은 처리량이 NPU 클럭을 따르므로 버림률이 늘 수 있다"는 일이 일어나지 않았습니다. 클럭 강등이 없었기 때문입니다.

**2. 처리량·버림·지연·표시 박자가 시간에 따라 변하지 않습니다.** 5분 구간 8개 사이 차이는 처리량 0.04 FPS, 버림 0.13%p, 지연 중앙값 0.1 ms 이내입니다. 짧은 측정(약 1분)의 값을 이 운용점의 정상 상태 값으로 써도 됩니다.

## 4. 주의·남은 일

- 1회입니다. 주변 온도는 기록하지 않았습니다(실내, 시작 SoC 66.7 °C).
- 기본 영상(덜 혼잡)만 썼습니다. 혼잡 장면(MOT20)은 GPU 후처리 부하만 조금 늘고 NPU 부하는 같아([`o2_mot20_02`](../../../technique_ablation/runs/o2_mot20_02/summary.md)), 칩 온도에 주는 차이는 작을 것으로 봅니다(재지 않음).
- 중간 운용점(b4s8 등)과 냉각 장치를 단 상태의 장시간 운용은 여전히 재지 않았습니다.
- 반복 영상(5.6 GB)은 `build/out/o2_soak/`에 남아 있습니다(git 밖).

# Blocker 1: FFmpeg Vulkan frame allocation fails on V3DV (all Vulkan hwaccels and hwupload)

## symptom (FFmpeg 8.1.3 pristine, -init_hw_device vulkan=vk:0 = V3D 7.1.10.2), FFv1 hwaccel decode:
Failed to create semaphore: VK_ERROR_INVALID_EXTERNAL_HANDLE
[ffv1 @ 0x55558e315c30] Failed setup for format vulkan: hwaccel initialisation returned error.
## same with hwupload only (no codec):
  ffmpeg -init_hw_device vulkan=vk:0 -filter_hw_device vk -f lavfi -i testsrc2=s=1920x1080 -frames:v 3 -vf format=yuv420p,hwupload,hwdownload,format=yuv420p -f null -
  -> Failed to create semaphore: VK_ERROR_INVALID_EXTERNAL_HANDLE / Failed to configure output pad on Parsed_hwupload_1
## system FFmpeg 7.1.5-0+deb13u1+rpt2 (/usr/bin/ffmpeg), same hwupload command: identical error (regression-free, long-standing)

## root cause (libavutil/hwcontext_vulkan.c, 8.1.3)
  device init (~l.1962): vkGetPhysicalDeviceExternalSemaphoreProperties(OPAQUE_FD) WITHOUT VkSemaphoreTypeCreateInfo -> queries BINARY semaphores
  create_frame (~l.2717-2786): creates TIMELINE semaphores and chains VkExportSemaphoreCreateInfo(OPAQUE_FD) if the (binary) query said EXPORTABLE
  V3DV: binary OPAQUE_FD exportable, timeline not exportable -> vkCreateSemaphore returns VK_ERROR_INVALID_EXTERNAL_HANDLE
  spec: VUID-VkExportSemaphoreCreateInfo-handleTypes-01124 (handleTypes must be supported as reported by VkExternalSemaphoreProperties)
  llvmpipe does not trigger it because it reports OPAQUE_FD not exportable even for binary.

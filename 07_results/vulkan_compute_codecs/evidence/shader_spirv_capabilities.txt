## summary
Every FFv1 decode/encode main shader, ProRes vld, ProRes RAW and dpx_unpack declare Int64 (V3D shaderInt64=false).
All decode output shaders declare StorageImageWriteWithoutFormat (V3D shaderStorageImageWriteWithoutFormat=false).
FFv1 decode, ProRes vld/idct and DPX declare RuntimeDescriptorArray; ProRes also ShaderNonUniform/StorageImageArrayNonUniformIndexing (V3D descriptorIndexing=false, runtimeDescriptorArray=false).
=> Using these modules on V3DV is invalid Vulkan usage (VUID-VkShaderModuleCreateInfo-pCode-08740: a declared capability's required feature must be supported/enabled); FFmpeg 8.1.3 does not check these features before creating the pipelines.
